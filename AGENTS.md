## Workspace persistence

Save new account-owned data and preferences in Supabase by default, with account access rules and cross-device refresh. Use browser storage only for demo data, temporary UI state, or an explicit offline cache. When replacing browser persistence, preserve and safely import existing data without overwriting newer cloud records. Include required SQL migrations and document setup steps.
